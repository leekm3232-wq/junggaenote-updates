# 중개노트 다운로드

[최신 설치 파일](https://github.com/leekm3232-wq/junggaenote-updates/releases/latest)

신규 설치는 junggaenote-starter.apk를 실행하세요. 약 114KB의 시작 앱에서 전체 기능 앱을 내려받습니다.
기존 사용자는 arm64-v8a 정식 APK를 기존 앱 위에 설치하세요. 앱을 삭제하지 마세요.
전체 기능 APK는 약 93MB이며 AI 모델은 별도 다운로드합니다. 이후 새 버전은 앱에서 자동 확인하고 Wi-Fi에서 다운로드합니다. Android 설치 확인은 필요합니다.

이 저장소에는 APK와 업데이트 목록만 배포합니다. 고객 데이터와 프로젝트 원본 소스는 포함하지 않습니다.
